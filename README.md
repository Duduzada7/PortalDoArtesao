# 🎨 Portal do Artesão

O **Portal do Artesão** é uma solução web desenvolvida para conectar a gestão pública municipal aos artesãos locais, simplificando a divulgação de eventos, o processo de candidatura e o credenciamento de profissionais da cultura.

---

## 🌟 O que a plataforma faz?

### 🏛️ Gestão Municipal (Administração)
* **Gerenciamento de Eventos:** Criação e controle de feiras, exposições e oficinas culturais.
* **Controle de Vagas:** Organização flexível de vagas por modalidades e especialidades artísticas.
* **Credenciamento:** Análise e aprovação de cadastros de artesãos do município.
* **Gestão de Acessos:** Painel para inclusão e controle de novos gestores.

### 🎨 Espaço do Artesão
* **Perfil Profissional:** Cadastro de especialidades, portfólio e informações de contato.
* **Candidaturas:** Inscrição rápida em feiras e eventos disponíveis na região.
* **Acompanhamento:** Painel simples para verificar o status de aprovação de perfil e de participação em feiras.

---

## 🛠️ Tecnologias Utilizadas

* **Backend:** PHP / Laravel
* **Frontend:** Blade / Bootstrap / JavaScript
* **Banco de Dados:** MySQL / PostgreSQL
